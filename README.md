# Social Meritocracy and Support for Democracy: A Cross-National Analysis

### Project Overview
This research project investigates the relationship between **Social Meritocratic Belief** 
and **support for democratic institutions**. By integrating data from the 
**World Values Survey (WVS) Wave 7** and the **EIU Democracy Index**, 
the study explores how perceptions of meritocracy shape political regime preferences 
across more than 50 countries.

### Quick Start: Replication Instructions
This project is designed for full automation. 
To replicate all tables and figures presented in the paper, please follow these steps:

1.  **Prerequisites**: Ensure you have [R](https://cran.r-project.org/) 
                      and [RStudio](https://posit.co/download/rstudio-desktop/) installed on your machine.

2.  **Initialize Project**: Double-click the **`Meritocracy_Democracy_Analysis.Rproj`** file 
                            in the root directory. This is a crucial step to ensure 
                            that all relative paths are correctly handled by the `here` package.

3.  **Run Pipeline**: Open and run the **`run_all.R`** script. 
    - The script will automatically check for and install any missing R packages via the `pacman` manager.
    - It will sequentially execute the entire pipeline: Data Cleaning (`01`), 
      Statistical Analysis (`02`), and Visualization (`03`).
      
4.  **Check Results**: All academic tables (`.tex`) and publication-quality 
                      figures (`.pdf`) will be automatically generated and saved in the `/output` directory.

### Software & Dependencies
- **R Version**: 4.0.0 or higher
- **Core Packages**: 
  - `tidyverse`: Core collection of packages for data science (includes `dplyr`, `ggplot2`, etc.)
  - `here`: Enables robust relative path management
  - `modelsummary` & `kableExtra`: Academic table formatting
  - `ggrepel`: Label placement in scatter plots
  - `scales`: Scale functions for visualization
  - `patchwork`: Combining multiple plots
  - `sf` & `rnaturalearth`: Geographic mapping and spatial data
  - `sensemakr`: Sensitivity analysis for causal inference
  
### Data Acquisition
This project uses the **World Values Survey (WVS) Wave 7** , **WVS Time Series** and **EIU Democracy Index** dataset. 
Due to licensing restrictions, the raw data is not included in this repository. 
To replicate the analysis, please download the following datasets and place them in the designated directory.

1. World Values Survey (WVS) Wave 7 and Time Series:
  -  **Download**: Visit the [WVS Official Website](https://www.worldvaluessurvey.org/WVSDocumentationWV7.jsp).
  -  **Format**: Download the WVS Cross-National Wave 7 and WVS Time Series Dataset in CSV format.
  -  **Placement**: Place the downloaded raw data file into the `/data/raw/` directory of this project.
  -  **Rename**: Ensure the filename matches the path specified 
    in `run_all.R`.

2. EIU Democracy Index:
  -  **Download**: Visit the [Economist Intelligence Unit (EIU)](https://www.eiu.com/n/campaigns/democracy-index-2022/)
  -  **Format**: Download the Democracy Index Dataset in CSV format.
  -  **Placement**: Place the downloaded raw data file into the `/data/raw/` directory of this project.
  -  **Rename**: Ensure the filename matches the path specified 
    in `run_all.R`.
  
### LaTeX Requirements for Tables
- To correctly compile the LaTeX tables generated by the R scripts in this project, 
  please ensure your LaTeX environment (e.g., Overleaf, MiKTeX, or TeX Live) has 
  the following packages installed:
  - `booktabs`: For professional-quality table horizontal lines
  - `threeparttable`: For aligning table notes with the table width
  - `ulem`: For text underlining and strikethroughs
  - `float`: For precise table positioning (`[H]`)
  - `graphicx`: Required if table scaling is used
  
- Troubleshooting -- Unicode Character Errors:
    - If you encounter an error regarding Unicode character − (U+2212) 
    (often caused by the minus signs generated by R), you must add the following 
    line to your LaTeX document's preamble:
    ```
    \DeclareUnicodeCharacter{2212}{-}
    ```
